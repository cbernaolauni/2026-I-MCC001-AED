Detailed Description

Iterador in-order bidireccional (forward/backward) para BTree.

Define BTreeTraversalDirection, BTreeFrame y la plantilla BTreeIterator, que recorre las claves de un B-Tree en orden ascendente o descendente usando una pila explícita en lugar de recursión.

Enumeration Type Documentation

◆ BTreeTraversalDirection

enum class BTreeTraversalDirection
strong

Sentido de recorrido in-order de un BTreeIterator.

Forward recorre las claves de menor a mayor (in-order izquierda->derecha). Backward recorre las claves de mayor a menor (in-order derecha->izquierda).
