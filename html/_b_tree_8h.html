Detailed Description

Contenedor BTree genérico, thread-safe, basado en Traits.

Envuelve una CBTreePage<Traits> raíz y expone la API pública del árbol (Insert, Remove, Search, Print), iteradores in-order (forward/backward) e integración con las funciones libres ForEach y FirstThat.
